# 多协议远程自动同步工具

Windows 桌面端远程文件自动同步工具，支持 FTP、FTPS、SFTP、rsync。适合网站维护、源码上传、服务器文件管理、多站点同步和日常项目部署。

> 说明：本仓库为公开发布仓库，只提供打包后的 Windows EXE、使用说明和校验信息，不发布原始源代码。

## 主要用途

- 本地网站源码修改后，自动同步到远程服务器
- 同时管理多个站点、多个服务器或多个目录
- 使用 FTP、FTPS、SFTP、rsync 进行远程文件同步
- 启动时自动对账，补同步软件未运行期间产生的文件差异
- 预检同步结果，提前查看将上传、跳过或删除的文件
- 通过规则保护远程关键文件，降低误删风险

## 支持协议

- FTP
- FTPS
- SFTP
- rsync

## 核心功能

- 多同步组管理：每个同步组独立配置协议、账号、本地目录和远程目录
- 实时文件监听：本地文件新增、修改、删除、移动后自动处理
- 启动对账：启动后扫描本地和远程差异，补上传漏掉的文件
- 预检/预分析：同步前先查看差异列表，不实际上传或删除
- 同步规则：只同步指定目录、后缀、文件名或通配符
- 忽略规则：排除缓存、日志、临时文件等不需要同步的内容
- 禁止删除规则：保护远程关键文件不被同步删除
- 删除保护：可保护 `.env`、`.user.ini`、`.htaccess`、图片附件等
- 冲突策略：支持覆盖、较新覆盖、大小不同覆盖、跳过、重命名、询问等
- 断线重连：连接异常后自动重试
- 队列持久化：异常退出后，未完成任务不会直接丢失
- 分组日志：多同步组运行时，每个同步组有独立日志页
- 配置备份：保存配置前自动备份旧配置，默认保留最近 5 份

## 快速使用

1. 下载发布包中的 `多协议远程自动同步工具.exe`。
2. 将 EXE 放到一个单独目录中运行。
3. 首次运行会自动创建同目录 `config.yaml` 和 `log/` 目录。
4. 在软件的“同步组”页面新增同步组。
5. 选择协议，填写主机、端口、账号、密码、本地目录和远程目录。
6. 先执行“预检”，确认将要同步的文件列表。
7. 点击“启动同步”，之后本地目录变化会自动进入同步流程。

## 重要提醒

- 首次配置真实服务器前，建议先执行“预检”。
- 如果远程服务器上有 `.env`、`.htaccess`、上传附件等重要文件，建议提前设置禁止删除规则。
- 不要把包含真实账号密码的 `config.yaml` 上传到公开网络。
- 本仓库不包含源码，不建议把它称为开源源码项目。

## 下载与校验

请在仓库 Release 或附件区域下载 EXE 文件。

当前构建文件信息见 [CHECKSUMS.txt](./CHECKSUMS.txt)。下载后可在 PowerShell 中校验：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\多协议远程自动同步工具.exe"
```

校验值一致时，说明文件未被修改。
